# أخضر — صفحة التحميل 🌿

صفحة الهبوط اللي بيوصل منها الزباين لتطبيق **أخضر** لطلب الخضار والفاكهة.
المنصورة.

## 🔗 الرابط

**<https://aldahshaneg-cloud.github.io/akhdar/>**

ده اللينك اللي يتبعت واتساب، أو يتحط في بايو فيسبوك وإنستجرام.

## إيه اللي فيها

- بتعرف نوع الجهاز لوحدها: الأندرويد بيشوف زرار تحميل مع خطوات التثبيت،
  والآيفون بيشوف رسالة "قريبًا" مع أزرار واتساب وتليفون بدل زرار ميّت.
- حجم الملف بيتقري من الملف نفسه، فمش بيبقى رقم قديم بعد أي نسخة جديدة.
- بيانات التواصل: تليفون، واتساب، قناة واتساب، وعنوان المحل على الخرايط.
- معاينة الرابط على واتساب فيها اللوجو والاسم.

## من فين بيجي ملف التطبيق؟

من **[صفحة الإصدارات](../../releases/latest)** بتاعة المستودع ده. الرابط
`releases/latest/download/akhdar.apk` بيوصّل دايمًا لآخر نسخة، فالصفحة
مش محتاجة تتعدّل مع كل تحديث — ارفع إصدار جديد وخلاص.

ملف الـ APK مش متحفوظ جوه المستودع عن قصد: ٢٤ ميجا مع كل نسخة كانت
هتفضل في تاريخ Git للأبد.

## تحديث نسخة جديدة

```bash
gh release create v1.0.1 akhdar.apk --title "أخضر 1.0.1"
```

الصفحة هتوصّل للنسخة الجديدة تلقائيًا.
